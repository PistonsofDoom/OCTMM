## Filters

### Overview

| Name | Description | Inputs |
|---|---|---|
| Resonator | Constant-gain bandpass resonator. Center frequency and bandwith in Hz | Input, Center Frequency, Bandwidth |
| Peak | Peaking filter | Input, Center Frequency, Q |
| Pinkpass | Pinking filter | Input |
| Panner | Mono to stereo panner. Pan input should between -1 -> 1 | Input, Pan |
| Notch | Notching filter | Input, Center Frequency, Q |
| Moog | Moog resonant lowpass filter | Input, Cutoff Frequency, Q |
| Morph | Filter that "morphs" between lowpass, peak, and highpass. Morph should be between -1 -> 1 | Input, Center Frequency, Q, Morph |
| Lowpole | One-pole lowpass filter | Input, Cutoff Frequency |
| Lowpass | Lowpass filter | Input, Cutoff Frequency, Q |
| Lowshelf | Low shelf filter with adjustable gain | Input, Center Frequency, Q, Gain |
| Highpole | One-pole highpass filter | Input, Cutoff Frequency |
| Highpass | Highpass filter | Input, Cutoff Frequency, Q |
| Highshelf | High shelf filter with adjustable gain | Input, Center Frequency, Q, Gain |
| Butterpass | Butterworth lowpass filter | Input, Cutoff Frequency |
| Bell | Bell filter with adjustable gain | Input, Center Frequency, Q, Gain |
| Bandpass | Bandpass filter | Input, Center Frequency, Q |
| Bandrez | Resonant two-pole bandpass filter | Input, Center Frequency, Q |
| Allpass | Allpass filter | Input, Center Frequency, Q |
